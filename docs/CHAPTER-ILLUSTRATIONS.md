# 章节演示插图

新建创作默认开启章节完成后自动规划并生成插图；旧草稿需主动点击生成。当前流程不包含 DeepSeek 图片自动审核，也不会因模型审核结果自动修正提示词或重画，不自动发布内容。

1. 本章正文完成后，DeepSeek 根据学习目标、要求和真实自然段判断是否需要插图，规划位置和内容提示词。每章最多两张，无需插图时保存理由。
2. 新创作默认采用用户指定的 [GraphRAG 文章插图](https://mp.weixin.qq.com/s/zjrfncJghdWihgWcMdyyKg)画风。每张图上传同一份 SHA256 固定的真实参考图，避免逐张漂移。旧稿锁定的风格继续沿用；使用原目录时，首张完成图作为全文样式锚。提示词和豆包比例控件均指定 16:9。
3. Playwright 操作独立豆包浏览器的正常新对话、生图、上传参考图、发送和下载按钮。人工登录、验证码等待机制保留，不自动解答验证。
4. 下载原图时由浏览器适配器检查文件签名和实际宽高；服务完成本地文件与16:9尺寸校验后，直接按精确段落锚点插入阅读稿、Markdown导出和发布副本。尺寸不符保留原文件及断点，不自动重画，可主动重新生成本章插图。

DeepSeek 仍负责规划图解和精简超长旧提示词；采集图片的信息提取也保留。图片生成后不调用视觉审核模型，不增加审核 token 消耗，不再显示内容、风格和排版自动通过的结论。尺寸校验仅说明文件和比例符合要求，不代表图中文字、箭头或知识准确性已获得认证。用户可看图后主动重新生成。

## 提示词与风格

通用规则在 src/illustration-prompts.mjs。先确定学习问题，再按实际知识选择流程、层级、分区、对比、关系图或循环。保留必要流程、分支、反馈与条件；分组不强加箭头，不固定卡片数量或左右布局。同级元素采用一致编码，图标与文字对应清楚。

内容提示词建议80至220字符，硬上限320字符，只含目标、元素、必要图内文字及关系。外层只附加一次16:9、简短风格和参考用途，不追加独立 labels 清单或图注。参考图不作为章节知识来源，不复制其文字和水印。旧提示词过长时由模型重新设计，不用字符串截断；旧词保存在提示词修订记录中。

风格目录及参考资产映射来自 [yang0/handraw-style](https://github.com/yang0/handraw-style)，固定版本 f4cba38b8682345168ccbcd80cf4f5a3d9feb761，来源与许可证保存在 third_party/handraw-style/。当前默认真实样图保存在 assets/illustrations/，不拼接上游长篇人物细节。

## 断点与手动操作

登录、验证、额度等待、暂停和服务重启保留断点；重启后需主动继续。人工处理完成后先检查原请求，不刷新或盲目重发。提交结果不确定时仍需人工核对，这是避免重复提交的机制，与已移除的图片模型审核无关。

旧审核阶段已下载的图片继续时直接本地校验并插入，不重新上传样图或生成。历史审核和失败记录保留，但不触发自动修正或审核。已完成的旧图片仍可查看及发布，不伪造新的审核通过记录。

豆包结果定位绑定原会话、提交和回复标识；多个无法区分的候选不取最后一张图。下载使用网站原有按钮，在独立E盘临时目录跟踪下载GUID和完成事件；每次下载重新指定当前上下文的路径。失败保留原请求以便再次下载。推广弹窗仅用网站原有关闭按钮处理，验证码继续等待人工。

手动 regenerate-illustrations 保留正文、插入锚点和风格，保存旧计划并创建新图片ID，清空新请求断点，不覆盖旧图。全文尚无样式锚图时可显式 replan-illustrations 重新选风格；已有锚图后不能自动更换。重新规划保留前三版历史。

样图上传前清空控件，等待预览可读且上传进度消失再提交。附件上传卡住可重传一次，两次超时则停止。此附件恢复不等于对图片内容自动重画。

## 正文与配置

原正文、内部章节结构和引用记录不改变，插图不计入80%—120%文本预算。正文改变时旧锚点失效，需重新规划。阅读稿不追加图注，简短标题仅作图片替代文本。发布准备不再依赖 visualReview 字段，仍检查图片完成状态、尺寸校验失败、正文匹配和锚点。

- doubaoProfileDir：沿用E盘独立持久化登录资料，不加入Git。
- doubaoCdpEndpoint：连接已打开专用浏览器，端点失效不自动切换空白资料。
- illustrationTimeoutMs：单图等待默认10分钟；人工登录验证不计时，可暂停。
- illustrationStylePreset：默认 author-graphrag；空值使用原风格目录。
- 原图：outputDir/creations/<创作ID>/illustrations/，UUID文件名，经图片路由提供。
- Markdown使用本地KnowFlow图片链接，离线分享需带原图并替换链接。

2026-11-10：因实际发现自动视觉审核会漏判箭头和关系错误，按用户要求移除此阶段及其自动重画分支。历史实测记录保留，不视为新版运行步骤。
