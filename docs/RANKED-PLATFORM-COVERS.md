# 图文完成后的平台封面

文案规划在同一次DeepSeek调用中先给3条不同切入角度的候选（copyStrategy），每条记录读者问题、正文连续原句、文章实际回应和画面关联，再选择最终headline。程序验证正文引句、候选唯一性、18字符上限和最终选择一致；这只能验证结构及引句存在，不能证明点击率或语义承诺成立。吸引力以正文中的具体矛盾、信息差、方法价值为依据，不用品牌加泛化动作充当点击理由，不夸大功能与收益。tags无必要则为空；候选与理由不印在封面中。该步骤不增加独立模型调用。

场景版研究额外逐张保存sceneTreatments：背景形态、主体表现、空间层次、互动方式。规划输出sceneDesign，分别描述具体背景和主体材质、姿态、表情；这两段必须编译到真实生图提示，不能只留在分析理由中。画面允许前中后景与辅助元素，保留明确主角和文字可读性。无相应观察时不得把平面图标当作玩偶，也不臆造参考场景。

文章创作新增可选“封面设计要求”，API字段direction，保存为本篇coverDirection并参与封面版本校验。具体品牌或角色由本文、主题资料或用户设计要求支持，不硬编码到通用模板；修改设计要求只使封面过期，不改标题、正文和章节插图。参考图继续只借设计语言。

新创作默认开启：章节正文 → 章节插图 → 全文图文校验 → 平台封面样本研究 → 独立封面生成 → 人工审核 → 发布系统复用并仅保存草稿。不开启插图时不会自动生成此类封面；现有完整图文可在创作画布下方点击“生成各平台封面”。

每个平台从当前采集任务按统一影响力指数由高到低遍历，读取实际图片宽高，只有与目标封面比例一致（相对偏差不超过5%）的图才能入选；像素尺寸可缩放，横版、竖版和方图不能互相凑数。匹配比例后仍按影响力排序，不再优先同平台的低分图。支持同一文章多个封面地址，首图比例不符时继续检查后续地址。记录原图宽高、目标比例和跳过原因；不足5张明确等待补图，不回退到不同比例样本。旧版研究缓存不会被误当成已通过尺寸筛选。公众号无独立采集渠道时明确标注“当前任务跨平台”。无封面、未知指数、不可读图片和完全重复图片不凑数；不足5张保留断点并提示补取，不调用视觉分析。采集分数只用于选样，不推断设计元素的因果效果。

一次向DeepSeek Flash发送5张实际图片和S1—S5编号，估算文字占比、主字字高、字重、对比、留白、文字行数及布局。每条共同画面规则必须列出至少两张支持样本。另外保留1—6条可迁移的视觉创意方法：大小反差、文字图形互动、视觉隐喻、裁切、负空间及信息压缩等。每条方法说明原理、具体画面操作、缩略图作用和实际支持样本；独特方法可由单张样本支持，不强行凑共同项。描述使用主文字、主图形、背景等抽象角色，不借用样本的文案、品牌、题材或具体物件。来源ID、平台、分数、文件校验和及跳过原因只留作审核。

封面文案和主题元素仅由完整文章、主题资料和读者认知背景独立决定。保留现有文章标题，另拟不超过18字符的封面短句，0—2个补充主题词和30—180字符主体提示。传给文案模型的参考信息经过字段白名单，保留数值、视觉枚举和抽象创意方法，不传样本文案、标题、自由备注或主题元素。DeepSeek选择1—2个真实方法编号，记录本文的视觉构思、方法转化及缩略图焦点，并把具体画面操作写入主体提示。新版本重新分析旧版未保留创意方法的结果。

DeepSeek另给出最终画幅内的主文字框、图形框、标题原文分行、字高、字重、对比及所用规则编号；程序检查安全区和近似文字容量，并将坐标、比例、分行明确编译成最终生图提示。主文字区域至少占22%，主字字高为画宽6%—18%，采用粗字强对比；允许标题与主体边缘穿插，不限定上下或左右模板。封面不再继承正文插画画风，可独立采用字体形变、色块、质感和图文咬合；单纯大字、强对比不算完整创意。所选方法中至少一条来自文字图形互动、视觉隐喻或裁切，并关联实际designReferenceId。豆包直接上传这个S编号的封面样本，只参考视觉设计，不照抄文案、品牌或主题对象。该参考图路径和SHA256写入断点，恢复时不会回退到正文样图。研究与规划各自对结构错误提供具体反馈，最多修正一次；不会新增图片生成后的模型审核阶段。

微信公众号900×383，抖音1080×1440；两平台独立提示词、生成断点与图片，继续沿用Seedream 5.5。公众号先在16:9原图中央设计2.35:1安全裁切区域；模型直接生成目标比例时也接受。新版中心裁切铺满画幅，旧版断点仍使用原完整画面补白适配。保留登录、验证码人工等待及额度断点，不加入图片自动审核。暂未接入渠道不假定尺寸。

创作页面保留5张样本、逐图观察、共同规律、支持编号、最终提示词及封面预览。正文、章节插图或画风变更会使封面过期，不能直接复用。发布副本只有标题、正文块和图像位置与已完成封面相符时才复用；不重复生图，不自动发表。旧发布副本继续保留自身断点，不强行替换旧封面。

API：POST /api/creations/:id/covers；GET /api/creations/:id/covers/:channel/image；GET /api/creations/:id/covers/:channel/references/S1（至S5）。所有生成仍在CreationService的可暂停工作槽内。

审核后可通过POST /api/creations/:id/covers/:channel/crop调整横版取景，参数centerY为0—1；只在无活动创作时处理已完成封面，保留原图和生成请求，记录裁切位置、原图及结果校验和，不重复生图。图文咬合布局允许文字框跨越图形区域，不强制填满同一个矩形；字号、安全区及文本容量仍受检查。当前系统入口支持单篇文章自动生成各平台封面，多篇文章的选择与排队入口尚未实现。

参考图的非主题文字由统一清理规则约束：不继承作者署名、账号名、头像水印、归属标记、系列名、页码，以及收藏、关注、点赞、转发、扫码、购买等引导话术或广告角标；保留本篇指定的标题、主题品牌和必要知识标签。删除位置自然衔接背景，不留空白占位，不改成新的账号或广告。规则同时进入DeepSeek规划和实际豆包提示词，记录referenceHygieneVersion。尚无提交断点的旧计划在首次提交前补入规则；已有提交记录、下载结果或完成封面保持原断点，不重复生成。实际模型执行仍需人工看图确认。
