# 文章创作：高影响力标题与平台封面

全文章节及插图完成后，创作流程先拟标题，再生成平台封面。新建创作默认启用两个步骤，也可分别关闭。旧创作在画布下方使用“生成／恢复标题方案”或“生成各平台封面”。独立标题操作不触发生图。

标题样本仅来自当前采集任务，按现有跨平台统一影响力分数降序选择前10个有效且不重复的标题，不要求有封面。相同来源与相同标题去重；不足10条停止，保留正文与插图。DeepSeek逐条抽象T1—T10的表达结构，再总结至少两条样本共同支持的结构。基于本文正文生成主标题、公众号与抖音各3个候选，并分别选用一个。标题候选保存结构编号、理由及本文连续原句依据。程序校验长度、样本对应和原句存在；格式不合格时将错误反馈给模型修正一次。该校验不能保证标题的全部语义判断正确，仍需人工审核。

主标题只替换Markdown首级标题并同步大纲标题；章节正文与插图段落锚点保持原样。两平台标题分别遵守公众号64字符、抖音30字符限制，发布副本和封面规划默认使用对应标题；发布时明确填写的人工标题优先。封面另拟独立的视觉短句，与文章标题互补，不要求逐字复用文章标题的术语或标签。

标题样本、结构、候选、原句依据、用量与重试记录保存在创作的titleWorkflow；完成结果断点复用。正文、章节审核状态或创作要求变化后结果失效；人工编辑主标题会让原自动标题方案失效，发布副本不再继续使用旧的自动标题。正文变化后的旧封面亦不能复用。生成失败、额度不足及验证码处理沿用原封面断点机制。

API：POST /api/creations/:id/titles，独立拟标题；POST /api/creations/:id/covers，默认先补齐标题再生成公众号与抖音封面。GET /api/creation-settings暴露titles能力。仅保存平台草稿，不自动发表。

高影响力样本用于借鉴表达结构，不能证明结构造成传播效果，也不保证新文章成为爆款。禁止从样本迁入未经本文支持的数字、收益承诺、权威背书与结论。

当前封面设计v3：先研究5张实际封面，再结合全文与读者认知说明，选择观众较容易识别的入口entryTerm。入口可以来自正文或主题资料，不必来自文章标题；品牌关联须能在资料中核对。entryReason保存认知与资料关联的理由。封面突出入口和一个通俗关注点，文章标题补充机制、范围与背景；不预设技术词、机器人、构图或口号，不将架构原型夸大成成熟可用产品。画风仅继承全文样图的线条、配色和字体，主体与构图另依主题设计。

封面区提供读者认知输入框。POST /api/creations/:id/covers支持audience（最多2000字符），保存为coverAudience；说明变化令封面失效，正文和文章标题保持原样。留空时结合样本与创作要求判断；单篇受众说明作为任务数据，不写入通用提示词。参考原文标题及不超过1600字符的片段仅核对主题身份，卖点以正文为事实边界。

封面短句最多18字符，精简生图提示词30—180字符；tags只补充主标题未表达且确有样本支持的信息。一次反馈全部长度、来源和去重问题，由模型修正一次，不由程序改写文案。设计规则版本变化保留原记录，复用同任务已完成的五图研究后重新规划。当前设计版本ranked-five-audience-entry-v3，视觉研究版本ranked-five-v1。
