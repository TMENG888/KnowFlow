同一个分数，保留不同平台的语境

影响力分衡量一条内容在同平台、同类型样本中的互动位置，便于跨平台排序。它不等同于全网触达人数或传播因果效果。

影响力 = 100 × 加权互动分位数

计算步骤

  1. 使用本机近90天采集库。相同平台与内容 ID 只取最近一份观测，按平台和文章／图文／视频类型分别建立参照样本。
  2. 对每项已观察到的互动数计算 log(1 + 数量)，求样本内经验分位数。并列数量取中秩，已确认零互动取0；未知值保留空值。
  3. 默认权重：点赞30%、评论30%、收藏25%、分享15%。对有足够参照的可用指标重新归一化权重，输出0—100分。

解读限制

同一参照组少于20条时标为试算；有效参照少于2条的指标不参与评分。各平台指标可见性不同，必须结合指标覆盖率一起阅读。少量样本不适合据此作运营决策，后续积累稳定的各平台背景样本后，才适合比较排名。

浏览／播放量单独保留，不与互动量相加。同文转载保留原平台记录与内容指纹，采集库不会将不同平台的点赞直接相加。评分随参照库增加而变化，导出文件包含评分版本、参照量与每项分位数。

从检索到可分析正文

  1. 输入检索词，选择平台和每平台目标量；默认开启视频音频转写。
  2. 点击开始统一采集。浏览器从可见搜索框提交检索，逐次点击列表卡片读取，关闭详情后再读下一条。知乎采用专用登录列表浏览器，将实际文章链接写入队列，由另一未登录浏览器读取详情；两侧不传递登录资料。
  3. 操作和阅读之间有可配置随机间隔；必须等待页面就绪，随机间隔不会代替加载核验。
  4. 遇到登录或验证时，点击对应平台的“打开登录”，在保留的页面内完成；页面恢复后自动接着原任务采集。安全停止会同时关闭自动恢复。
  5. 安全限制按本机、平台保存保护等待，不会由其他平台的继续按钮清除。网络风险需要人工处理，等待期内不重复访问。
  6. 点击内容标题查看正文、图片与视频原始链接、视频字幕和证据；通过 JSON 或 CSV 导出所选任务。

完成量如何计数

图文和文章必须取得详情正文；视频必须取得平台字幕或完成音频转写，且通过基础质量检查。搜索摘要、仅有标题、转写失败、超过时长限制或需人工复核的视频保留记录，但不计入完整主体内容目标。

运行与存储

工作台仅监听本机地址。SQLite 保存任务、正文、断点和日志；E盘任务输出目录保存截图、音频和字幕。每次只运行一个统一检索任务，任务内最多5个平台独立窗口并发；视频转写默认单并发。服务中断后保留断点，需手动继续。关闭工作台标签页不会终止后台任务。

目前提供本机运行版。该版参考既有分布式工程的保护、断点、增量保存和转写流程，任务与登录资料独立存储；横向分布式节点和Redis队列不属于本次本机版功能。
